# Diyan Maner — Portfolio

Minimalist, Apple-inspired personal portfolio website built with semantic HTML5, modern CSS, and vanilla JavaScript.

## Tech Stack
- **HTML5:** Semantic markup, accessibility (WCAG AA), SEO meta tags, Open Graph.
- **CSS3:** Apple SF Pro system stack with fallbacks, custom properties, fluid clamp() typography, mobile-first responsive design, frosted-glass navbar.
- **JavaScript:** Lightweight vanilla JS for mobile menu toggles, accessible keyboard navigation, and real-time category filtering.
- **Zero build steps:** Pure static site deployable to GitHub Pages, Vercel, or Netlify.

## Structure
- `/index.html` — Homepage with punchy narrative hero, featured backend work, and editorial research strip.
- `/projects.html` — Project catalog with live filtering and deep-dive technical specs.
- `/research.html` — IITM case study and publication in Ocean Digest.
- `/about.html` — Technical skill matrix, engineering background, and academic history.
- `/contact.html` — Direct email, location, phone, social profiles, and pre-addressed message composer.
- `/404.html` — Minimalist 404 error page.
- `/css/style.css` — Design system and component styling.
- `/js/main.js` — Client-side interactions.
- `/assets/` — Favicon and resume.
